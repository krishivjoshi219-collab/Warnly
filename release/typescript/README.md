### Running the Distribution
```bash
# 1. Unzip the release package
unzip warnly-typescript-v1.1.0.zip -d warnly-web

# 2. Host with any static web server (or open index.html directly)
cd warnly-web
npx serve .
# Or using Python:
python3 -m http.server 3000
```
